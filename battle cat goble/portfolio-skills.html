Technical Highlights
  • EMVCo QR payload จากศูนย์ — เขียน TLV encoder + CRC-16 CCITT ด้วยมือทั้งหมดโดยไม่ใช้ library ใดๆ รองรับทั้ง 3 ประเภท PromptPay ID ตามมาตรฐาน
  • Atomic stock reservation — ใช้ Supabase PATCH + Prefer: count=exact เพื่อ update เฉพาะ row ที่ยัง available อยู่เท่านั้น ป้องกัน double-sell โดยไม่ต้อง lock table
  • Auto-release expired reservations — reactive cleanup pattern ที่ตรวจ expired order ตอน admin เปิดดู stock หรือมีลูกค้าใหม่มาซื้อ ไม่ต้องใช้ cron job
  • Revenue calculation ที่แม่นยำ — filter เฉพาะ status=done, exclude admin accounts, ใช้ base_amount แยกค่าธรรมเนียม TrueMoney ออก — คำนวณถูกทั้งรายวันและรายเดือนจาก shared helper เดียว
  • Built and shipped solo — ออกแบบ, develop, deploy, และดูแล production system คนเดียว ตั้งแต่ database schema จนถึง Cloudflare configuration
